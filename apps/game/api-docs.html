Breakmine API

Accounts, authentication and player skins for breakmine.com. Machine-readable description: /openapi.json (OpenAPI 3.1). Discovery: /.well-known/api-catalog (RFC 9727).

Base URL

HostNotes
https://breakmine.comServes the site and the API.
https://api.breakmine.comAPI only, no static site.

Authentication

Obtain a token with POST/api/login, then send it on every authenticated request as a bearer token. Tokens are JWTs signed with HS256 and last 7 days; POST/api/logout revokes one before it expires. 

Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Accounts and authentication

POST/api/register

Create an account. No authentication.

FieldRules
username3-32 chars, a-z A-Z 0-9 _ -
password6-128 chars
curl -X POST https://breakmine.com/api/register \
  -H 'Content-Type: application/json' \
  -d '{"username":"spinningcubes","password":"correct-horse"}'
StatusResponse
201{"message":"User created successfully","username":"spinningcubes"}
400{"error":"Username must be at least 3 characters"}
409{"error":"Username already taken"}
429Too many requests.

POST/api/login

Exchange credentials for a JWT. No authentication. Rate limited to 10 requests per 15 minutes.

curl -X POST https://breakmine.com/api/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"spinningcubes","password":"correct-horse"}'
{"token":"eyJhbGciOiJIUzI1NiIs...","expiresIn":"7d"}

Wrong credentials return 401 {"error":"Invalid credentials"}. An unknown username takes the same time to answer as a wrong password, so it does not leak which accounts exist.

POST/api/logout

Revoke the presented token. Requires authentication.

curl -X POST https://breakmine.com/api/logout \
  -H "Authorization: Bearer $TOKEN"
{"message":"Logged out successfully"}

GET/api/user/{username}

Public profile lookup. No authentication.

curl https://breakmine.com/api/user/spinningcubes
{"username":"spinningcubes","created_at":1757308800000,"last_login":1759200000000,"has_skin":true}

Unknown users return 404 {"error":"User not found"}.

Skins

POST/api/upload_skin

Upload a PNG skin for the authenticated user, replacing any previous one. Requires authentication.

Maximum 256 KB. A 64×64 image is cropped to its top 64×32 face region on retrieval; any other size is served as stored. Only image/png is accepted. 

curl -X POST https://breakmine.com/api/upload_skin \
  -H "Authorization: Bearer $TOKEN" \
  -F 'file=@skin.png'
{"message":"Skin uploaded successfully","filename":"3f2a1c9e8b7d6054.png"}

A non-PNG file, a missing file, or one over the size limit returns 400. Repeat uploads are rate limited to 10 per 15 minutes.

GET/skin/{username}

Fetch a skin as image/png. No authentication.

curl -o skin.png https://breakmine.com/skin/spinningcubes

A user with no skin returns 404 {"error":"Skin not found"}.

Errors

Error responses are JSON objects with a single error string:

{"error":"Missing or invalid authorization header"}

400 validation failure, 401 missing/expired/revoked token, 404 no such user or skin, 409 username taken, 429 rate limited, 500 server error.

Status

Liveness probe, referenced by the catalog's status relation:

curl https://breakmine.com/api/status
{"status":"ok","timestamp":"2026-09-30T00:55:29.202Z","version":"1.0.0"}
